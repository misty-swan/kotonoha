# kotonoha（言の葉）

日本語の文章を、**品のある、美しい日本語**に整える Claude スキルです。

飾りを足すのではなく、雑音を削り、言葉を選び直します。目指すのは、上質なコピーライターが手を入れたような、静かで端正な文章です。

> Proofreads and refines Japanese text into elegant, refined prose — fixing honorific (keigo) errors, slang, hype, redundancy and inconsistent notation, without adding or altering facts.

## インストール

```bash
npx skills add misty-swan/kotonoha
```

## 使い方

Claude に日本語の文章を渡して、次のように頼むだけです。

- 「この文章を校正して」
- 「品のある文章に整えて」
- 「このメール、もう少し上品な言い回しにして」
- 「商品紹介文を美しい日本語に推敲して」

Claude は、次の形で返します。

1. **校正後の全文**
2. **主な修正**：原文、修正、理由の一覧
3. **確認してほしい点**：好みが分かれる表現、意味が二通りに読める箇所、事実を補うと良くなる箇所

## 何を直すか

修正は三つの層に分かれます。

| 層 | 内容 | 扱い |
|---|---|---|
| 誤り | 敬語の誤用（二重敬語、尊敬語と謙譲語の取り違え）、ら抜き・さ入れ・い抜き、重言、慣用句の誤用、文体の混在、主語と述語のねじれ | 必ず直す |
| 品位 | 俗語・話し言葉、過剰な敬語、「させていただく」の多用、誇張と煽り、感嘆符と絵文字、ぼかし言葉、なじみの薄いカタカナ語 | 原則として直す |
| 美しさ | 冗長の削減、文末の単調さ、一文の長さ、語順と読点、和語のやわらかさ、言い過ぎない抑制 | 文書の種類に合わせて加減する |

## 守ること

- **事実を足さない、変えない。** 数値、固有名詞、日付、主張はそのまま残します。原文にない情景や具体例も創作しません。
- **書き手の声を保つ。** 意味、主張の強さ、敬意の向きは変えません。
- **文書の形式を保つ。** 省略や余韻といったコピーの技法は、原文がコピーのときだけ使います。
- **整っている文は直さない。** 直す必要がなければ、そう伝えます。
- **好みが分かれるものは直さない。** 「〜になります」「お伺いする」などは、指摘するだけにとどめます。

## 機械チェック（任意）

外部ライブラリに頼らない点検スクリプトを同梱しています（Node.js 18 以降）。

```bash
node skills/kotonoha/scripts/check.mjs 文章.txt
echo "本文" | node skills/kotonoha/scripts/check.mjs --json
```

正規表現で検出するため、誤検出もあります。スキルはこの結果を手がかりにとどめ、すべてを機械的に直すことはしません。

## 構成

```
skills/kotonoha/
├── SKILL.md              手順と原則
├── references/
│   ├── keigo.md          敬語
│   ├── goi.md            語彙（俗語、誇張、記号、カタカナ語、和語と漢語）
│   ├── bunsho.md         文章（冗長、文の長さ、文末、語順と読点、余白、コピーの技法）
│   ├── hyoki.md          表記（仮名で書く語、送り仮名、数字、記号、文法上の誤り）
│   ├── touten.md         読点（打つ位置と打たない位置、過不足、統一）
│   └── sources.md        出典と根拠の扱い
└── scripts/
    └── check.mjs         機械チェック
```

## 根拠について

ルールは、【規範】と【推奨】に分けて書いています。

- **【規範】**：文化審議会「公用文作成の考え方」（2022年）、「敬語の指針」（2007年）、文化庁「国語に関する世論調査」、JTF日本語標準スタイルガイドなど、公的な基準に裏付けのあるもの。
- **【推奨】**：書き言葉の慣行と、このスキルの文体方針にもとづくもの。

詳しくは [`sources.md`](skills/kotonoha/references/sources.md) を参照してください。
