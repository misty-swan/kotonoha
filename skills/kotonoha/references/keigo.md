# 敬語：正しく、重ねすぎず

敬語は、相手との距離を整える道具です。足りなければ失礼になり、重ねすぎれば慇懃無礼になって品を落とします。目指すのは、正確で簡潔な敬語です。

凡例：【規範】は公的な基準で裏付けのある項目です。【推奨】は書き言葉の慣行とこのスキルの方針にもとづく項目です。出典は `sources.md` にまとめています。

## 1. 二重敬語【規範】

同じ種類の敬語を一つの語に重ねたものです。「敬語の指針」は、一般に適切ではないとしています。

| 誤 | 正 |
|---|---|
| おっしゃられる | おっしゃる |
| ご覧になられる | ご覧になる |
| お越しになられる | お越しになる／いらっしゃる |
| お帰りになられる | お帰りになる |
| お読みになられる | お読みになる |
| 拝見させていただく | 拝見する |
| 拝読させていただきました | 拝読しました |
| 伺わせていただきます | 伺います |
| お伺いさせていただきます | 伺います |
| 申し上げさせていただきます | 申し上げます |

### 直さないもの

**習慣として定着した二重敬語**：「敬語の指針」は次の語を許容しています。誤りとして扱いません。

- 尊敬語：お召し上がりになる、お見えになる
- 謙譲語：お伺いする、お伺いいたします、お伺い申し上げる

文脈上より簡潔にしたいときは、「召し上がる」「伺います」を「確認してほしい点」で提案してもかまいません。

**二重敬語ではないもの**

- 「ご説明いたします」「ご案内いたします」：謙譲の「ご〜する」に丁重語の「いたす」が付いた形で、適切です（文化庁「国語に関する世論調査」平成19年度の解説）。
- 敬語連結：別々の語にそれぞれ敬語が付いた形で、「敬語の指針」は許容しています（例：お読みになっていらっしゃる）。ただし長くなるなら簡潔にします（例：お読みになっています）。

## 2. 「させていただく」【規範＋推奨】

**基本の用法**【規範】：相手の許可を得て行い、それによって自分が恩恵を受ける場合に使います（文化庁「国語に関する世論調査」平成19年度の解説）。

- ○ 資料をコピーさせていただけますか。（許可を求めている）
- ○ 先日は泊めていただき、ありがとうございました。

**許可も恩恵もない場面**【推奨】：「いたします」「します」で足ります。

| 原文 | 修正 |
|---|---|
| ご報告させていただきます。 | ご報告いたします。 |
| 本日はこれで終了させていただきます。 | 本日はこれで終了いたします。 |
| 資料を送付させていただきます。 | 資料をお送りいたします。 |
| 担当させていただく山田です。 | 担当の山田です。 |

一通の文書に何度も出るとくどくなります。必要な一か所だけ残し、ほかは「いたします」「します」に替えます。

**さ入れ言葉**【規範】：五段動詞（休む、行く、読む、書く、帰るなど）には「さ」を入れず、「〜せていただく」とします。一段動詞（見る、来る、決めるなど）とサ変動詞は「〜させていただく」で正しい形です。

| 誤 | 正 |
|---|---|
| 休まさせていただきます | 休ませていただきます |
| 行かさせていただきます | 行かせていただきます |
| 読まさせていただきました | 読ませていただきました |
| 帰らさせていただきます | 帰らせていただきます |

## 3. 尊敬語と謙譲語の取り違え【規範】

相手の行為には尊敬語、自分側（自分、自社、身内）の行為には謙譲語を使います。

| 誤 | 正 | 理由 |
|---|---|---|
| （相手に）受付で伺ってください | 受付でお尋ねください | 「伺う」は謙譲語 |
| （相手に）拝見してください | ご覧ください | 「拝見」は謙譲語 |
| （相手に）参られますか | いらっしゃいますか／お越しになりますか | 「参る」は丁重語 |
| （相手が）申されたとおり | おっしゃったとおり | 「申す」は丁重語 |
| （社外へ）弊社の部長がおっしゃいました | 弊社の部長が申しておりました | 身内に尊敬語は使わない |
| 私の御計画 | 私の計画 | 自分側に尊敬語は使わない |
| （客に）どうぞいただいてください | どうぞお召し上がりください | 「いただく」は謙譲語 |

## 4. 接客マニュアル調の言い回し【推奨・要確認】

評価が分かれるため、誤りとは断定しません。書き言葉では、より簡潔な形を提案します。

| 原文 | 提案 |
|---|---|
| こちらが資料になります | こちらが資料です／資料でございます |
| ご注文のほうをお伺いします | ご注文を伺います |
| よろしかったでしょうか | よろしいでしょうか |
| 1万円からお預かりします | 1万円をお預かりします |
| ご案内させていただく形になります | ご案内いたします |
| ございますでしょうか | ございますか |

## 5. 「お」「ご」の付け方【推奨】

- **自分側の物には付けない**：私のお電話番号 → 私の電話番号。ただし、相手に向かう自分の行為（「お電話いたします」「ご連絡いたします」）は謙譲の表現として適切です。
- **付けすぎない**：お料理のお写真をおつけしましたので、ご覧ください。→ 料理の写真を添えましたので、ご覧ください。
- **外来語には原則として付けない**：おビール、おソースなど。ただし慣用として定着したものは、文脈に応じて残します。
- **定着した語は直さない**：ご飯、お茶、お礼、お知らせ、ご挨拶、お手洗いなど。

## 6. 慇懃無礼を避ける【推奨】

敬語を重ねるほど距離が開き、かえって冷たく見えます。要所に一つ、きちんとした敬語があれば十分です。

- 原文：ご確認いただけますと幸いに存じますので、何卒よろしくお願い申し上げます。
- 修正：ご確認いただけますと幸いです。どうぞよろしくお願いいたします。

「いただきたく存じます」は誤りではありません。一通に一度なら品よく効きますが、続けると重くなります。

---

## 7. 書き言葉の品のある定型【推奨】

使いすぎると型どおりで冷たく見えます。一通に一、二か所を目安にします。原文にない定型を足すのは、ユーザーが求めたときか、明らかに礼を欠く場合に限ります。

| 場面 | 原文の例 | 品のある形 |
|---|---|---|
| 依頼 | 〜してください | 〜していただけますでしょうか／〜いただけますと幸いです |
| 依頼の前置き | （なし） | 恐れ入りますが／お手数をおかけしますが／差し支えなければ |
| お詫び | すみません | 申し訳ございません／失礼いたしました |
| 重いお詫び | 本当にすみませんでした | ご迷惑をおかけしましたこと、心よりお詫び申し上げます |
| 感謝 | ありがとうございます | そのままで十分に品がある。改まるなら「心より御礼申し上げます」 |
| 断り | できません | いたしかねます／お受けいたしかねます |
| 断りの前置き | （なし） | あいにく／せっかくのお申し出ですが |
| 承知 | 了解しました | 承知しました／かしこまりました |
| 結び | よろしくです | 引き続きよろしくお願いいたします |

「了解しました」を目上への言葉として失礼とみなす人がいます。改まった文書では「承知しました」が無難です。ただし誤りとは断定しません。
