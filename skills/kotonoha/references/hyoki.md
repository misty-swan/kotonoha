# 表記：そろっていることが品の土台

表記の乱れは、内容より先に目に入ります。正しく、そろっていることが、品の土台です。

基準は、文化審議会「公用文作成の考え方」（2022年）と、JTF日本語標準スタイルガイドです。ユーザーや媒体に独自の表記規定があれば、そちらを優先します。

**大原則**：どちらが正しいかよりも、一つの文書の中でそろっていることを優先します。原文がすでに一貫した表記で書かれていれば、それに合わせます。

凡例：【規範】は公的な基準やスタイルガイドで裏付けのある項目です。【推奨】は慣行にもとづく項目です。

## 1. 仮名で書く語【規範】

| 漢字 | 仮名 | 補足 |
|---|---|---|
| 〜して下さい | 〜してください | 補助動詞。物をもらう意味の「下さる」は漢字でもよい |
| ご確認頂く | ご確認いただく | 補助動詞。物をもらう意味の「頂く」は漢字でもよい |
| ご案内致します | ご案内いたします | 補助的な用法 |
| 出来る | できる | 「出来事」「出来栄え」は漢字 |
| 行う事 | 行うこと | 形式名詞。具体的な事柄は「事」 |
| 〜する時 | 〜するとき | 形式名詞。時刻や時期を指すなら「時」 |
| 〜する所 | 〜するところ | 形式名詞。具体的な場所は「所」 |
| 〜する物 | 〜するもの | 形式名詞。具体的な物体は「物」 |
| 以下の通り | 以下のとおり | 数字のあとは「2通り」 |
| 予め | あらかじめ | |
| 更に | さらに | |
| 尚 | なお | |
| 但し | ただし | |
| 又は | または | 法令文では「又は」 |
| 及び | および | 法令文や公用文では「及び」 |
| 概ね | おおむね | |
| 殆ど | ほとんど | |
| 是非 | ぜひ | 「是非を問う」は漢字 |
| 宜しく | よろしく | |
| 何時 | いつ | |
| 活気付く | 活気づく | 接尾語の「〜づく」 |

## 2. 送り仮名【規範】

本則に従います。

| 誤・許容 | 本則 |
|---|---|
| 行なう | 行う |
| 表わす | 表す |
| 現われる | 現れる |
| 終る | 終わる |
| 浮ぶ | 浮かぶ |
| 取扱う | 取り扱う |
| 申込む | 申し込む |

慣用として定着した名詞は、送り仮名を省きます。例：申込書、取締役、売上金。

## 3. 数字【規範】

- 横書きでは算用数字を使う。
- 大きな数は3桁ごとに区切る：5,000円、62,250人。
- 「兆」「億」「万」は漢字で書く：1億2,000万円、30万人。
- 慣用句や熟語は漢数字にする：一つ、一人、一度、一石二鳥、二者択一、七五三。
  - 「1つ」と「一つ」は基準によって異なる（JTF は数量なら「1つ」）。文書の中でそろえる。
- 序数は算用数字で書く：第3回、2番目。
- 概数は漢数字で書く：数十人、二十余人。
- 助数詞の「か」は、算用数字なら「3か所」「3か月」、漢数字なら「三箇所」とする。

---

## 4. 記号【規範】

- 句読点は「、」と「。」にする。「，」「．」は、文書全体で統一されている場合に限って残す。
- 算用数字とアルファベットは半角にする：１２３ → 123、ＡＢＣ → ABC。
- 半角カタカナは使わない：ﾒｰﾙ → メール。
- 和文の中の括弧、疑問符、感嘆符は全角にする：（）？！。
- 三点リーダー「……」とダッシュ「――」は、二つ重ねる。
- 括弧の中で文が終わる場合は、括弧の中に句点を打つ。ただし、名詞だけ、または引用の場合は打たない。
- 見出しには句点を付けない。

---

## 5. 外来語【規範＋推奨】

- 語末の長音は付ける：コンピューター、ユーザー、エディター、メモリー【規範：公用文、JTF】。
- ただし、IT分野などで「サーバ」「ユーザ」と長音を付けない表記が定着している文書は、その表記で統一する【推奨】。
- カタカナ語が長く連なるときは、中黒「・」か半角スペースで区切る：グラフィック・ユーザー・インターフェース【規範：JTF】。

## 6. 文法上の誤り【規範】

**ら抜き言葉**：一段動詞とカ変動詞の可能形から「ら」が抜けた形です。書き言葉では直します。

| 誤 | 正 |
|---|---|
| 見れる | 見られる |
| 来れる | 来られる |
| 食べれる | 食べられる |
| 寝れる | 寝られる |
| 着れる | 着られる |
| 出れる | 出られる |
| 決めれる | 決められる |

五段動詞の可能動詞（書ける、読める、行ける）は正しい形です。直しません。

**い抜き言葉**：「〜ている」の「い」が抜けた形です。書き言葉では直します。

| 誤 | 正 |
|---|---|
| 見てる | 見ている |
| 持ってます | 持っています |
| 読んでた | 読んでいた |

**さ入れ言葉**：`keigo.md` の「させていただく」の項を参照してください。

**二重否定**：意図がない限り避けます【規範：公用文】。例：しないわけではない → することもある

## 7. 慣用句の誤用【規範：辞書の本来の形】

| 誤 | 正 |
|---|---|
| 汚名挽回 | 汚名返上／名誉挽回 |
| 怒り心頭に達する | 怒り心頭に発する |
| 上へ下への大騒ぎ | 上を下への大騒ぎ |
| 押しも押されぬ | 押しも押されもせぬ |
| 二の舞を踏む | 二の舞を演じる／二の足を踏む |

**要確認として扱うもの**

次の表現は、本来の形とされるものがある一方で、許容する辞書や見解もあります。そのため直さずに、本来の形を「確認してほしい点」で提案します。

| 表現 | 本来とされる形 | 補足 |
|---|---|---|
| 的を得る | 的を射る | 近年は許容する辞書もある |
| 采配を振るう | 采配を振る | 「振るう」も広く使われている |
| 足元をすくわれる | 足をすくわれる | 「足元」も広く使われている |
| 熱にうなされる | 熱に浮かされる | 熱で悪夢を見る意味なら「うなされる」で正しい |
| 役不足 | 力不足 | 「実力に比べて役目が軽すぎる」という本来の意味なら正しい |

## 8. 表記ゆれ【推奨】

次のような語は、どちらの表記を選ぶかより、文書の中でそろっていることを優先します。原文でより多く使われている表記に合わせます。

- 子供／子ども
- 様々／さまざま
- 一つ／1つ／ひとつ
- 申込み／申し込み
- 引越し／引っ越し
- 打合せ／打ち合わせ
- Web／ウェブ
- メールアドレス／メアド（メアドは俗語なので「メールアドレス」に統一）
