# 語彙：雑音を削り、言葉を選び直す

品のある文章は、硬い文章ではありません。「すごく」を「非常に」に、「やる」を「実施する」に機械的に置き換えると、事務的になるだけです。原文の温度に合う言葉を選びます。

この章の言い換え候補には「やわらかく」と「改まって」の幅があります。メールやビジネス文書なら「改まって」、ブログや紹介文なら「やわらかく」を起点にします。

凡例：【規範】は公的な基準で裏付けのある項目です。【推奨】は書き言葉の慣行と、このスキルの方針にもとづく項目です。

## 1. 話し言葉・俗語【推奨】

| 原文 | やわらかく | 改まって |
|---|---|---|
| すごく／めっちゃ／めちゃくちゃ | とても、本当に | 大変、非常に |
| 超〜 | とても〜 | 大変〜 |
| マジで／ガチで | 本当に | まことに |
| やばい（良い意味） | 驚くほど〜／思わず声が出るほど | 何がどう良いのかを具体的に言う |
| やばい（悪い意味） | 困った、危うい | 深刻な、厳しい |
| ぶっちゃけ | 正直なところ | 率直に申し上げると |
| ほぼほぼ | ほぼ、ほとんど | おおむね |
| ちゃんと | きちんと | 確実に、正確に |
| いっぱい | たくさん | 多く、数多く |
| なので（文頭） | ですから、そのため | したがって |
| でも（文頭） | けれども、ただ | しかし、とはいえ |
| 〜とか | 〜や、〜など | 〜など |
| 〜みたいな | 〜のような | 〜のような |
| 〜じゃない | 〜ではない | 〜ではありません |
| 〜しちゃう／〜しちゃった | 〜してしまう | 〜してしまいました |
| 〜しなきゃ | 〜しなければ | 〜する必要があります |
| 〜って（主題） | 〜は、〜というのは | 〜とは |
| ゲットする | 手に入れる | 入手する |
| 〜的な感じ | 〜のような | 削る |
| ｗ／笑／（笑） | 削る | 削る |

口語の味が書き手の個性になっているエッセイやブログでは、全部を直す必要はありません。誤解を招く語や、場にそぐわない語だけを直します。

## 2. 強すぎる言葉と誇張【推奨】

対象：最高、最強、究極、圧倒的、完璧、神〜、絶対、史上最〜、根拠のないNo.1

- 程度を一段落とすか、削る。「とびきり」「心から」「本当に」のように、誇張せずに気持ちを伝える語を選ぶ。
- 原文の中にその良さを示す事実（素材、数字、手間）があれば、そちらに語らせる。事実がない場合は創作しない。

| 原文 | 修正 |
|---|---|
| 最高においしいパンです！ | とびきりおいしいパンです。 |
| 絶対おすすめです！ | 心からおすすめします。 |
| 圧倒的な使いやすさ | 驚くほどの使いやすさ／使いやすさ（形容を削る） |

保証や約束の中身（「絶対に返金します」など）は、和らげると意味が変わります。直さずに確認へ回します。

## 3. 売り込みと煽りの言葉【推奨】

対象：今だけ、今すぐ、急いで、お見逃しなく、必見、激安、爆売れ、衝撃の、話題沸騰、損する

- 事実（期間、数量、価格）は残し、煽りの語だけを外す。
- 読み手を急かさず、選ぶ理由のほうを示す。

| 原文 | 修正 |
|---|---|
| 今だけ！限定50個、急いで！ | 50個限定でご用意しました。 |
| 見なきゃ損！衝撃の新作 | 新作が届きました。 |

上の一つ目の例では、「今だけ」が期間を指すのか分からないため削っています。期間が決まっているなら、日付を補うよう確認で提案します。

**自分で価値を名乗らない**：高級感あふれる、上質な、こだわりの、極上の、ワンランク上の。こうした語を連ねると、かえって安く見えます。一つに絞るか、原文にある事実に語らせます。

## 4. 記号と装飾【推奨】

- **感嘆符「！」**：本文では原則使わず、句点で静かに終える。親しみを出したい告知でも、一つの文書に一つまでにする。
- **「！？」「!!」「〜〜」「ー！」**：使わない。
- **絵文字、顔文字、♪★♡**：外す。ブランドの方針として使う場合は、ユーザーの指定に従う。
- **三点リーダー**：「…」は二つ重ねて「……」とする。多用しない。
- **「w」「笑」「（笑）」**：外す。

---

## 5. ぼかし言葉【推奨】

対象：〜かなと思います、〜かと思います、〜的な、〜みたいな感じ、〜という形で、〜のほう、〜させていただく形

- 事実は言い切る。意見は「と思います」で受けるが、続けない。
- 「〜と思います」が三回続いたら、二つは言い切る。
- 依頼、断り、反論など、柔らかさが礼儀になる場面では、適度に残す。

| 原文 | 修正 |
|---|---|
| 来週には届くかなと思います。 | 来週には届く見込みです。 |
| 資料という形でお送りします。 | 資料にしてお送りします。 |

## 6. カタカナ語【規範＋推奨】

「公用文作成の考え方」は、一般になじみのない外来語は言い換えるか、説明を添えるとしています【規範】。

| カタカナ語 | 言い換え |
|---|---|
| アジェンダ | 議題 |
| エビデンス | 根拠、裏付け |
| コンセンサス | 合意 |
| スキーム | 枠組み、仕組み |
| ペンディング | 保留 |
| リスケ | 日程の変更 |
| フィックス | 確定 |
| アサイン | 割り当て、任命 |
| ソリューション | 解決策 |
| ブラッシュアップ | 磨き上げる、練り直す |
| マスト | 欠かせない、必須 |
| ローンチ | 公開、発売 |
| ジャストアイデア | 思いつきですが |

- 定着した語（メール、パソコン、スケジュール、デザインなど）は直さない。
- 業界の読み手に向けた文書で定着している語は残す。

## 7. 和語と漢語【推奨】

漢語が連なると、文が黒く硬く見えて事務的になります。和語でほどくと、やわらかく品が出ます。ただし、幼くならない程度にとどめます。

| 漢語 | 和語 |
|---|---|
| 開始する | 始める |
| 実施する | 行う |
| 確認する | 確かめる |
| 使用する | 使う |
| 選択する | 選ぶ |
| 継続する | 続ける |
| 到着する | 着く、届く |
| 変更する | 改める、変える |
| 提供する | お届けする、ご用意する |
| 購入する | 求める（相手には「お求めになる」） |

- 名詞が「の」でつながった漢語の塊は、動詞を使ってほどく。例：申込書類の提出期限の延長について → 申込書類を出す期限を延ばすことについて／申込書類の提出期限を延ばします
- 逆に、和語ばかりで間延びするときは、漢語で引き締める。
- 説明文や資料では、正確さのために漢語を残してよい。

## 8. 季節と気遣いの言葉（手紙・挨拶文）【推奨】

原文に時候の挨拶がなければ、ユーザーが求めない限り足しません。すでにある挨拶を整えるときの参考にします。

**漢語調**：改まった手紙やビジネス文書に使う。「〜の候」の形で、そのあとに「貴社ますますご清栄のこととお慶び申し上げます」と続けるのが典型です。

| 月 | 例 |
|---|---|
| 1月 | 新春の候、厳寒の候 |
| 2月 | 余寒の候、立春の候 |
| 3月 | 早春の候、春分の候 |
| 4月 | 陽春の候、春暖の候 |
| 5月 | 新緑の候、薫風の候 |
| 6月 | 梅雨の候、初夏の候 |
| 7月 | 盛夏の候、猛暑の候 |
| 8月 | 残暑の候、晩夏の候 |
| 9月 | 初秋の候、新涼の候 |
| 10月 | 秋冷の候、清秋の候 |
| 11月 | 晩秋の候、向寒の候 |
| 12月 | 師走の候、初冬の候 |

**和語調**：親しい相手や、やわらかな案内文に使う。例：桜の便りが聞かれるころとなりました。／朝夕は、ずいぶん涼しくなりました。

**結び**：どうぞご自愛ください。／季節の変わり目、くれぐれもお体を大切になさってください。
