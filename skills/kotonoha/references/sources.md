# 出典と根拠の扱い

このスキルのルールは、次の三種類に分けています。

- **【規範】**：公的機関の基準やスタイルガイドで裏付けのあるもの。誤りとして直します。
- **【推奨】**：書き言葉の慣行と、このスキルの文体方針にもとづくもの。品と美しさのための提案です。
- **【慣習】**：慶弔の文（`keicho.md`）で使う区分です。公的な基準はなく、「そう受け取る人がいる」ことへの配慮です。複数の出典が一致する【慣習（広く一致）】は直し、出典で割れる【慣習（割れる）】は直さずに知らせ、語呂合わせなどだけを理由とする【俗説・好み】は指摘しません。

【推奨】の多くは、特定の出典ではなく、一般的な書き言葉の慣行にもとづいています。読み上げ原稿の項目（`yomiage.md`）の【推奨】は、主に NHK 放送用語委員会の記録にもとづきます。放送局の運用は公的な基準ではないため、【規範】とはせず、項目ごとに出典を添えています。数値の目安（一文80字、読点4つ、漢字の7字連続）は、このスキル独自の目安です。

## 主な出典

### 公的な基準

- 文化審議会「公用文作成の考え方」（建議、2022年1月）
  - https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/93650001_01.html
  - 対象：表記の原則、仮名で書く語、数字、符号、冗長表現、一文一義、文体の統一、二重否定、外来語の言い換え、同音語への配慮（解説 Ⅱ－5）、耳で聞いて分かりにくい漢語（解説 Ⅱ－8）、結論を先に示す構成（解説 Ⅲ－4）
  - 一文の長さ（解説 Ⅲ－3）は「一概に決められない」と留保したうえでの目安（50〜60字）
- 文化審議会「敬語の指針」（答申、2007年2月）
  - https://www.bunka.go.jp/seisaku/bunkashingikai/sokai/sokai_6/pdf/keigo_tousin.pdf
  - 対象：敬語の5分類、二重敬語、習慣として定着した二重敬語、敬語連結
- 文化庁「国語に関する世論調査」平成19年度
  - https://www.bunka.go.jp/tokei_hakusho_shuppan/tokeichosa/kokugo_yoronchosa/h19/
  - 対象：「させていただく」の基本用法、さ入れ言葉、「ご説明いたします」の適切さ、「私の御計画」の誤用
- 内閣告示「送り仮名の付け方」「外来語の表記」、常用漢字表
- 文部省「くぎり符号の使ひ方〔句読法〕（案）」（1946年）
  - 対象：読点の基本（文の中止、副詞的な語句の後、接続詞や感動詞の後、提示した語の後、引用の「と」の扱い、誤読を防ぐ読点）と、「読み飛ばしても文が通じるか」という判断基準
  - 現行の公用文の基準ではない。数字の位取りなど、現在の運用と異なる部分は採用していない

### スタイルガイドと道具

- JTF日本語標準スタイルガイド（翻訳用）第1.1版、日本翻訳連盟
  - 対象：仮名で書く語、送り仮名、全角と半角、記号、数字、外来語の長音
- textlint-ja のルール群（preset-ja-technical-writing、ja-no-redundant-expression、no-doubled-joshi ほか）
  - https://github.com/textlint-ja
  - 対象：`scripts/check.mjs` の検出項目の設計（冗長表現、ら抜き言葉、二重否定、助詞の連続など）

### 放送の言葉（読み上げ原稿）

- NHK 放送文化研究所「放送用語委員会」の記録（『放送研究と調査』掲載、2006〜2025年）
  - https://www.nhk.or.jp/bunken/research/kotoba/ （一覧は https://www.nhk.or.jp/bunken/d/research/kotoba/page/1/ ）
  - 主に参照した回：第1289回「文章の省略やねじれに注意しよう」、第1290回「放送の文章のくふう」、第1293回「ポーズ次第で伝わり方が変わる」、第1297回「聞く人の立場でわかりやすい表現をくふうしよう」、第1324回「わかりやすい文の構造に」、第1325回「耳で聞くことを前提に語順や語感を考える」、第1331回「「書きことばの音声化」ではなく，「話しことば」を」、第1345回「耳で聞いてわかりやすい表現･語順」、第1361回「話しことばの「線条性」を意識する」、第1362回「漢語や硬い表現を避け，わかりやすく」、第1367回「文の組み立てをわかりやすく」、第1371回「二とおりに聞き取れる表現を避ける」、第1374回「耳で聞いてわかりやすい表現を」、第1460回「長文は短く」
  - 対象：話し言葉で書くこと、漢語の言い換え、語順と主語・述語の距離、連体修飾、文の長さ、ポーズ、同音語
- NHK 放送文化研究所「放送における数字の読み方」（2026年8月）：数字の読み方
- 田中英輝・美野秀弥「日本語母語話者による「やさしい日本語ニュース」の読解実験」（言語処理学会第17回年次大会、2011年）：短く切りすぎた文は「電報文の羅列」のようになるという指摘
- 『NHKことばのハンドブック』『NHK日本語発音アクセント新辞典』は、本文を確認していないため、出典にしていない

### 慶弔の文

慶弔の言葉遣いに公的な基準は見つかりませんでした。次の出典を、【慣習】の判定に使っています（すべて 2026-11-19 取得）。ブライダルや葬儀の情報媒体は互いに参照し合っている可能性があるため、一致していても独立した裏付けとは数えにくい点に注意します。

- 日本郵便「お悔やみのレタックス」マナー：https://www.post.japanpost.jp/service/send/domestic/web/webletax/manner-choji.html
  - 対象：弔事の忌み言葉（死を直接いう言葉、重ね言葉、四と九）、宗教による違い、故人の家族の敬称
- 日本郵便「手紙の基礎知識 マメ知識」：https://www.post.japanpost.jp/enjoy/culture/howto/navi/mame_knowledge.html
  - 対象：頭語と結語の対応、前文の要素
- ゼクシィ「結婚式の忌み言葉」（監修：岩下宣子）：https://zexy.net/article/app002004019/
  - 対象：慶事の忌み言葉、重ね言葉を文脈で判断する考え方
- All About（中山みゆき、吉川美津子、森川さゆり、井上明美の各記事）：慶事・弔事の忌み言葉、宗教語、年賀と喪中
- みんなのウェディング、dime、ダ・ヴィンチWeb、Oggi、アシスト、serai：慶事の忌み言葉と重ね言葉、句読点を打たない慣習と、その薄れ方
- コトバンク「忌み詞」「重ね言葉」（精選版 日本国語大辞典、デジタル大辞泉）：語の定義

### 文章術と言い換え

- 国立国語研究所「外来語」言い換え提案（2002〜2006年）
  - https://www2.ninjal.ac.jp/gairaigo/
- 本多勝一『日本語の作文技術』：修飾の順序、読点の打ち方、リズムと文体の章立てを参照。読点の二大原則（長い修飾語の境目、語順を入れ替えた箇所）は、これを分析した論文（村越行雄「句読点の方法論的分析」）で確認
- 石黒圭による読点の調査：読点を文法・文体・修辞の三種類に分ける考え方（インタビュー記事 https://koubo.jp/article/60919 による）
- 読点の数の目安は、公的な基準には見当たらない。textlint の max-ten（既定で一文に読点3つまで）を参考に、このスキルの目安を決めた
- 文章読本の系譜（谷崎潤一郎、三島由紀夫、丸谷才一）：本スキルでは特定の主張を引用していない。文体を磨くための読み物として挙げる

## 判断が分かれるもの

次の表現は、立場によって評価が分かれます。そのため、誤りとして直さず、要確認として扱います。

- 「〜になります」「よろしかったでしょうか」などの接客敬語
- 「お伺いする」「お召し上がりになる」（敬語の指針では許容）
- 「いただきたく存じます」「ございますでしょうか」
- 「了解しました」（目上の人に使う場合）
- 「違和感を感じる」「被害を被る」
- 「的を得る」「采配を振るう」「足元をすくわれる」「熱にうなされる」「役不足」
- 「減らさせていただく」のように、「す」で終わる五段動詞の使役形（正しい形だが、さ入れ言葉と見分けにくい）
