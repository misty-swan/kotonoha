# 文章：リズムと余白

語を正しく選んだら、次は文の形を整えます。目指すのは、声に出して心地よく、言い過ぎず、読み手に余白を残す文です。

凡例：【規範】は公的な基準で裏付けのある項目です。【推奨】は広く知られた作文の原則と、このスキルの方針にもとづく項目です。

## 1. 冗長を削る【規範＋推奨】

「公用文作成の考え方」は、回りくどい言い方や不要な繰り返しを避けるよう求めています【規範】。

| 原文 | 修正 |
|---|---|
| 利用することができます | 利用できます |
| 検討することが可能です | 検討できます |
| 調査を実施しました／調査を行いました | 調査しました |
| 〜となっております | 〜です |
| 〜させていただいております | 〜しております |
| 有効であると言えます | 有効です／有効と言えます |
| 〜と言っても過言ではありません | 言い切るか「〜と言えます」 |
| 〜という形で | 削るか、「〜として」「〜にして」 |
| 〜のほうを | 〜を |
| 基本的に、一応、とりあえず | 意味がなければ削る |
| 教育費の増加と医療費の増加により | 教育費と医療費の増加により |

「〜を行う」が改まった響きのために選ばれている場合は、残してかまいません。

## 2. 重言【規範＋推奨】

同じ意味の語を重ねた表現です。

| 原文 | 修正 |
|---|---|
| 頭痛が痛い | 頭が痛い／ひどい頭痛がする |
| まず最初に | まず／最初に |
| 一番最初 | 最初 |
| 後で後悔する | 後悔する |
| 馬から落馬する | 落馬する |
| 必ず必要 | 必要／必ず要る |
| 今現在 | 現在／今 |
| 一番ベスト | 最善／ベスト |
| 返事を返す | 返事をする |
| 元旦の朝 | 元旦 |
| 約20名くらい | 約20名／20名くらい |
| 各都道府県ごとに | 各都道府県で／都道府県ごとに |
| 第1日目 | 第1日／1日目 |
| 諸先生方 | 諸先生／先生方 |

「違和感を感じる」「被害を被る」は許容する辞書や見解もあるため、誤りと断定せず要確認とします。

## 3. 一文一義と文の長さ【規範＋推奨】

「公用文作成の考え方」は、一文を短くし、一文の論点を一つにするよう求めています【規範】。

- 目安：「公用文作成の考え方」の解説は、適当な長さは「一概に決められない」としたうえで、50〜60字ほどになったら読みにくくなっていないか意識するとよい、としています。このスキルでは、50〜60字を意識しつつ、80字を超えたら分けられないかを必ず検討します（80字はこのスキル独自の目安です）。
- 「〜が、〜て、〜し、〜ので」と接続助詞で延々つなぐ文は区切ります。
- 短文ばかりが続くと、幼く、ぶつ切りに見えます。長い文と短い文を交ぜます。
- 文学的な長文や、リズムのために書かれた長文は残します。
- 読み上げる原稿では、字数より前後の文の関係で切るかつなぐかを決めます（`yomiage.md` §3-4）。

例

- 原文：新しい制度は来月から始まりますが、手続きの方法が変わるので、事前に説明会を開く予定ですが、参加できない方には資料をお送りします。
- 修正：新しい制度は来月から始まります。手続きの方法が変わるため、事前に説明会を開く予定です。参加できない方には、資料をお送りします。

## 4. 文末の変化と文体の統一【規範＋推奨】

**文体を混ぜない**【規範】：一つの文書の中で、敬体（です・ます）と常体（だ・である）を混ぜません。ただし、エッセイなどで書き手が意図して切り替えている箇所は残します。

**文末の単調さを避ける**【推奨】：同じ文末が三回以上続くと単調になります。

- 変化の付け方：「です」と「ます」を交互にする、二つの文を一つにまとめる、名詞文を動詞文にする、など
- 例
  - 原文：当店は駅から徒歩5分です。営業は10時からです。定休日は水曜日です。
  - 修正：当店は、駅から徒歩5分の場所にございます。営業は10時から、定休日は水曜日です。

意図した反復（「〜だ。〜だ。」と畳みかける表現）は、リズムを生む技法です。残します。

読み上げる原稿では、丁寧な文末が続くのは自然です。この項目は緩めて扱います（`yomiage.md` §6）。

## 5. 語順と読点【推奨】

**語順**

- 修飾語は、かかる語のすぐ前に置く。
- 修飾語が複数あるときは、長いものを先に、短いものを後に置く。
- 二通りに読める語順は、意味を確かめて直す。意味が決められないときは、直さずに確認へ回す。

例：「小さな駅前の古い喫茶店」は、「小さい」のが駅なのか喫茶店なのかが曖昧です。喫茶店が小さいのなら、「駅前の、古くて小さな喫茶店」と直します。

**読点**

打つ位置、打たない位置、打ちすぎと打たなすぎの判断は、`touten.md` にまとめています。読点を足すか削る前に、語順を入れ替えれば読点が要らなくならないかを考えます。

## 6. 係り受けとねじれ【規範＋推奨】

| 原文 | 修正 | 問題 |
|---|---|---|
| 私の夢は、パン屋を開きたい。 | 私の夢は、パン屋を開くことです。 | 主語と述語のねじれ |
| この商品の特徴は、軽くて丈夫です。 | この商品の特徴は、軽くて丈夫なことです。 | 主語と述語のねじれ |
| 本を読んだり、映画を見るのが好きです。 | 本を読んだり、映画を見たりするのが好きです。 | 「〜たり」は対で使う |
| 本年の当課の取組の中心は | 本年、当課が中心に取り組むのは | 「の」の三連続 |
| 会議で資料で説明した | 会議で、資料を使って説明した | 同じ助詞の連続 |

## 7. 体言止め【推奨】

- 体言止めは、一か所で使うから効きます。続けると箇条書きのように冷たく、ぶつ切りに見えます。
- ビジネスメールでは使いません。案内文や紹介文では一、二か所まで、コピーの見出しなら使ってかまいません。
- 体言で止めたら、次の文で受け止めて着地させます。

## 8. 漢字と仮名の配分【規範＋推奨】

**仮名で書く語**【規範：公用文作成の考え方、JTF日本語標準スタイルガイド】

- 形式名詞：こと、とき、ところ、もの（ただし具体的な物や場所を指すときは漢字）
- 補助動詞：〜ていく、〜てみる、〜ておく、〜てください、〜ていただく
- 補助的に使う「いたす」「いただく」：ご案内いたします、ご確認いただく
- 可能の「できる」（出来事、出来栄えは漢字）
- 副詞と接続詞の一部：あらかじめ、さらに、なお、ただし、または、おおむね、ほとんど、ぜひ、よろしく

詳しくは `hyoki.md` を参照してください。

**見た目の配分**【推奨】

- 漢字が続くと、紙面が黒く硬くなります。仮名ばかりだと、幼く間延びします。
- 比率の数値は決めません。出典によって目安が食い違うためです。紙面の「白さ」と読みやすさで判断します。
- 漢字が七字以上続いたら、助詞を補うか和語でほどきます。

## 9. 余白と抑制【推奨】

品のある文章の芯です。文書の種類を問わず、これを意識します。

- **いちばん言いたいことを、一度だけ言う。** 同じ主張を言葉を変えて繰り返さない。
- **形容を重ねない。** 例：とても上質で贅沢な、極上の時間 → 上質な時間
- **説明しすぎない。** 読み手が補える接続や理由（「なので」「ですから」）は、省けることがある。
- **自ら名乗らない。** 「心を込めて」「こだわりの」を連ねず、原文にある事実に語らせる。
- **急かさない。** 結論を押しつけず、読み手が判断する余地を残す。

## 10. コピーの技法（原文がコピーのときだけ）【推奨】

原文がキャッチコピー、見出し、短い宣伝文のときだけ使います。メールや説明文に使うと、気取って見えたり意味が薄れたりします。

- **一つの文に一つのことを書く。**
- **感情を説明せず、情景で示す。** ただし情景は原文にあるものだけを使い、新しく創作しない。
- **省略する。** 読み手が補える部分は書かない。ただし飛躍は一歩までにする。
- **曲言を使う。** 直接言わず、言外に示す。原文の主張（「最高水準」など）を言い換えると、意味が変わることがある。その場合は案として示し、採用は書き手に委ねる。
- **余韻を残す。** すべてを言い切らず、一歩手前で止める。
- **修辞は一か所だけ。** 反復、対句、倒置、誇張は、一つのコピーに一か所までにする。
- **声に出して確かめる。** 音の数、つかえる箇所、同じ音の連続（「〜の〜の」「〜て、〜て」）を確かめる。

**複数案を出す**

短いコピーは、方向の違う案を2〜3示し、それぞれの狙いを一言添えます。

例

- 原文：とても軽くて使いやすくて、毎日持ち歩きたくなる最高のバッグです！
- 案A：毎日、持ち歩きたくなる軽さ。（軽さを主役にした一行）
- 案B：軽い。だから、毎日連れていける。（理由で結ぶ）
- 案C：使いやすく、軽やかに。毎日のためのバッグです。（説明を残した穏やかな形）

どの案にも、原文にない事実は足していません。
