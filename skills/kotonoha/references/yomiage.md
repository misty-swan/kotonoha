# 読み上げ原稿：耳で聞いて美しい日本語

挨拶、司会、スピーチ、ナレーション、館内アナウンスなど、人が声に出して読む原稿の整え方です。

目で読む文章を、そのまま声にしても、聞き手には届きにくくなります。漢語が続き、中黒や括弧が並び、一文に情報が詰まった文は、目で読めば分かっても、耳では追えません。NHK の放送用語委員会は、これを「書きことばの音声化」と呼び、放送では「話しことば」で書くよう求めています。

目指すのは、声に出したときに自然で、聞いて心地よい日本語です。品のある文章の芯（`SKILL.md`）は変わりません。静かで、言い過ぎず、端正であることを、耳の側から整えます。

凡例：【規範】は公的な基準で裏付けのある項目です。【推奨】は放送の現場の知見と、このスキルの方針にもとづく項目です。放送局の運用は公的な基準ではないため、【推奨】に含め、出典を添えています。

## 1. 聞き手の条件

聞き手は、次の三つの条件のもとで原稿を受け取ります。直す理由に迷ったら、ここに戻ります。

- **前から順に、一度しか聞けない。** 読み返すことも、先を見ることもできません（NHK 放送用語委員会 第1361回「話しことばの「線条性」を意識する」）。
- **字が見えない。** 漢字の意味、記号、改行、括弧は伝わりません。同じ音の語は区別できません。
- **話し手の声で受け取る。** 書き言葉の硬さは、話し手の人柄の硬さとして聞こえます。

## 2. 言葉を選ぶ

### 2-1. 漢語の名詞を、動詞や形容詞の文に開く【規範＋推奨】

「公用文作成の考え方」は、漢語は「耳で聞いたときに分かりにくいものが多い」とし、和語への言い換えを勧めています【規範】。放送の現場では、「〜化」「〜停止」のような漢語の名詞を、動詞や形容詞を使った文に開いて直しています【推奨】。

| 原文 | 修正 | 出典 |
|---|---|---|
| 販売停止を余儀なくされた | 販売を停止しなければならなかった | NHK 放送用語委員会 第1345回 |
| 審査が厳格化 | 審査が厳しくなり | 同 |
| 撤去は困難を極めています | 取り除くのは、難しくなっています | 同 第1362回 |
| 転々とせざるをえませんでした | 転々としなければなりませんでした | 同 |
| 送信すると／閲覧ができます | 送ると／見ることができます | 同 第1289回 |
| 個人情報の取得・利用から保管・提供・廃棄に至るまで | 個人情報を取得するときから、利用、保管、提供を経て、廃棄するときまで | このスキルの事例 |

ただし、漢語には正確さや重みもあります。法令の用語、正式な名称、その場で通じている専門語は残します（例：「安全管理措置」）。和語にして幼くなるなら、元の語を残します。

### 2-2. 縮めた言葉は、補って広げる【推奨】

目で読めば一瞬で分かる短い熟語も、耳では聞き取りにくくなります。

- 原文：家族最多 → 修正：家族の中で最も多い（NHK 放送用語委員会 第1345回）
- 原文：今年から初参戦します → 修正：今年から初めて参戦します（同 第1324回）
- 原文：必要になりそうなデータが多岐にわたる → 修正：たくさんの種類のデータが必要になりそうだ（同 第1345回）

### 2-3. 日常の言葉を選ぶ【推奨】

その分野の言葉や、文書でしか使わない言葉は、聞き手が毎日使う言葉に置き換えます。

- 原文：展示方法 → 修正：見せ方（NHK 放送用語委員会 第1325回）
- 原文：顧客の開拓 → 修正：多くのお客さんに来てもらうように（同 第1290回）
- 原文：該当する → 修正：あたる

外来語は、なじみの薄いものを言い換えるか、ひと言で説明を添えます（同 第1290回）。

### 2-4. 同じ音の語と、二とおりに聞こえる言い方を避ける【規範＋推奨】

「公用文作成の考え方」は、同音の語は「口頭で伝えたり、音声サービスに用いたりする場面も想定し」て、言い換えるよう求めています【規範】。

- 耳では区別できない例：好成績と高成績、郷土食と郷土色（NHK 放送用語委員会 第1371回「二とおりに聞き取れる表現を避ける」）
- 同じ種類の例：私立と市立、科学と化学
- 二とおりに聞こえる例：「いかに安全に育てられているか」は「とても安全に」とも聞こえる → 「安全に育てられているかどうか」（同 第1325回）

言い換えられないときは、読み分けや言い分けを、読みの注記として示します（9 を参照）。「市立」を「いちりつ」と読むのは、「私立」と区別するための言い方です（デジタル大辞泉）。「私立」を「わたくしりつ」、「化学」を「ばけがく」と言い分ける慣行もありますが、放送の基準としては確認していません。

### 2-5. 決まり文句と、同じ形容詞の重ねを避ける【推奨】

「〜につなげていきたい」のような決まり文句は、何をしたいのかを具体的に言います（NHK 放送用語委員会 第1324回）。同じ形容詞を何度も重ねると、押しつけがましく聞こえます（同 第1289回）。

## 3. 文を組み立てる

### 3-1. 主語と述語を近づける【規範＋推奨】

「係る語とそれを受ける語」は近くに置きます（「公用文作成の考え方」）【規範】。耳では、主語を覚えたまま述語を待つのが、目よりもずっと難しくなります。主語と述語のあいだに、別の主語と述語を挟まないようにします（NHK 放送用語委員会 第1324回、第1290回）【推奨】。

- 原文：警察は、患者の状態を把握しないまま手当てをしたことが事故につながったとして、担当していた看護師を近く、業務上過失致死の疑いで書類送検する方針です。
- 修正：担当していた看護師が、患者の状態を把握しないまま手当てをしたことが事故につながったとして、警察は、この看護師を近く、業務上過失致死の疑いで書類送検する方針です。

（NHK 放送用語委員会 第1374回。「看護師」を前に出し、「警察」を後ろに下げることで、二組の主語と述語がそれぞれ近くなる。原文は「書きことば」としては完璧な文だが、耳で聞くと負担になる。文を分けずに、語順だけで聞きやすくしている。）

### 3-2. 長い連体修飾は、文を分ける【推奨】

名詞の前に長い修飾が付くと、聞き手は、何の話かを最後まで待たされます。「長い連体修飾は避け，2 文に分けるなど工夫が必要」（NHK 放送用語委員会 第1367回）です。

- 原文：那須産の卵料理には、栃木県が全国トップクラスの生産量を誇る、ニラのソースを合わせました。
- 修正：那須産の卵を使った料理には、ニラのソースを合わせました。ニラは、栃木県が全国トップクラスの生産量を誇る野菜です。

（NHK 放送用語委員会 第1345回。）

### 3-3. 言い切ってから、例や詳しいことを続ける【規範＋推奨】

「結論は早めに示し、続けて理由や詳細を説明する」（「公用文作成の考え方」）【規範】。耳で聞く原稿では、とくに効きます。

- 原文：委託先経由のサイバー攻撃による大規模な情報流出や、メールの誤送信・書類の誤封入といった日常業務の中のヒューマンエラーによる漏洩事案が相次いでいます。
- 修正：最近、全国の自治体や公的機関で、個人情報の漏えいが相次いでいます。委託先がサイバー攻撃を受け、大規模な情報流出につながったケースもあれば、メールの誤送信や書類の誤封入といった、日々の業務の中でのヒューマンエラーによるものもあります。

### 3-4. 文の長さ：分けるのが基本。ただし、話の流れを切らない【推奨】

長い文は、係り受けが乱れやすいので分けるのが基本です（NHK 放送用語委員会 第1460回「長文は短く」）。一方で、短く切りすぎた原稿は「電報文の羅列のように」なり、不自然に聞こえます（NHK 放送技術研究所、田中・美野 2011）。

聞き手は、句点のところで話がひと区切りついたと受け取ります。そこで、読み上げる原稿では、`bunsho.md` §3 の一文一義と字数の目安をそのまま当てはめず、前後の文の関係を見て決めます。

- **つなぐ**：前の文が、後ろの文の前提になっているとき。後ろの文が前の文の帰結、目的、依頼にあたるときや、前の文が「いつ」「どんなときに」という状況だけを述べ、肝心の出来事が後ろの文にあるときです。前の文だけでは、聞き手が「それで？」と待つことになります。
- **切る**：後ろの文が、前の文の例、詳しい説明、別の話題、締めの挨拶にあたるとき。前の文で言い切ったほうが、頭に入ります。

例

- 原文：法改正により、今は国や地方公共団体にも全国共通のルールが適用されています。個人情報を取得するときから…厳格な管理が求められています。
- 修正：…全国共通のルールが適用されており、個人情報を取得するときから…厳格な管理が求められています。（法改正と、その結果として求められることは一続きの話）

- 原文：研修動画を視聴します。何が個人情報にあたるのか…を確認します。
- 修正：研修動画を視聴し、何が個人情報にあたるのか…を確認します。（見ることと、それで確かめることは一つの流れ）

- 原文：入社した年の冬、私は大きな失敗をしました。そのとき、課長が声をかけてくれました。
- 修正：入社した年の冬、私が大きな失敗をしたとき、課長が声をかけてくれました。（前の文は、後ろの出来事の状況）

長い一文を分けるときも、前提と出来事のあいだで切らないようにします。前提の部分が長いなら、前提の中で切ります。つないで一文が長くなりすぎるときは、3-1 の例のように語順を直すか、3-2 で修飾をほどきます。読点を足すだけで済ませません。

つなぐときは、原文にない関係を足さないようにします（8 を参照）。

### 3-5. 並べるときは、数を絞り、言葉でつなぐ【規範＋推奨】

「公用文作成の考え方」は、三つ以上の情報を一文に並べるときは箇条書を使うよう求めています【規範】。読み上げでは箇条書が使えないので、「〜と〜」「〜や〜」で二つずつまとめるか、順を追って言います（「〜から、〜を経て、〜まで」）【推奨】。並べる範囲が分かりにくいときは、「〜だったり、〜たりする」のように範囲を示します（NHK 放送用語委員会 第1289回）。

## 4. 声にならない記号と数字

記号は声になりません。読み上げ原稿の本文には残さず、言葉に置き換えます【推奨】。

| 記号 | 直し方 | 例 |
|---|---|---|
| 中黒（・） | 読点でつなぐ、「や」「と」でつなぐ、順を追って言う | 誤送信・誤封入 → 誤送信や誤封入 |
| 括弧（（ ）） | 括弧の中身を本文に溶かすか、別の文にする。読まない補足なら削らずに確認へ回す | 研修（約30分） → 約30分の研修 |
| 二重括弧・鉤括弧（『』「」） | 題名や引用は、「〜という」で示す。原稿の中では一種類にそろえる | 『個人情報保護法の概要』を視聴し → 「個人情報保護法の概要」という動画を視聴し |
| ダッシュ（―）、三点リーダー（…） | 句点か読点に置き換える。間を置きたいなら、文を分ける | |
| スラッシュ（／） | 「または」「や」「と」に言い換える | 受付／会計 → 受付と会計 |
| 波ダッシュ（〜） | 「から」と読める形にする | 10時〜12時 → 10時から12時まで |
| 米印（※） | 本文に溶かすか、確認へ回す | |

数字は、算用数字のままで読み方が一つに決まるなら残します。読み方が二とおりあるもの（「1日」は「いちにち」か「ついたち」か）や、桁の大きい数は、聞いてすぐ分かる形を選びます。「0」は「ゼロ」か「れい」か、後ろの単位によって読み方が変わります（NHK 放送文化研究所「放送における数字の読み方」）。迷うものは、読みの注記に回します。

**〇〇や△△などの伏せ字**は、そのまま読まれてしまいます。本文には残したうえで、「確認してほしい点」で「読む前に入れてください」と伝えます。

## 5. 読点と間

読み上げる原稿の読点は、意味の区切りであると同時に、話し手が息をつく場所でもあります【推奨】。

- **意味の読点が先。** 誤読を防ぐ位置の読点（`touten.md` §1）は、読み上げでも変わりません。
- **息継ぎの読点は、許す。** 目で読む文章では `touten.md` §2-1 と §3 に従って読点を控えますが、読み上げ原稿では、息が続かない箇所に打つ読点を残します。呼びかけや前置きの後（「皆さん、」「本日は、」）、長い主語の後などです。
- **間の位置で、意味が変わる。** 同じ文でも、どこで間を置くかで伝わり方が変わります（NHK 放送用語委員会 第1293回「ポーズ次第で伝わり方が変わる」）。かかり先を誤解されそうな箇所は、語順を変えるか、読点の位置を変えて、間で意味を示します。

読点を増やすのは、文の組み立てを直したあとです。読点をいくつ打っても、組み立ての分かりにくさは救えません。

## 6. 文末と丁寧さ

- **「〜ます。」が続いても、気にしすぎない。** 挨拶や案内では、丁寧な文末が続くのが自然です。`bunsho.md` §4 の文末の変化は、目で読む文章ほど厳しく求めません。四回、五回と続いて単調に聞こえるときだけ、二つの文を一つにまとめます【推奨】。
- **丁寧さを変えない。** 「確認します」を「確認していきましょう」に、「ご覧ください」を「見てください」に変えると、話し手と聞き手の距離が変わります。やわらげたほうがよいと思っても、本文は原文の丁寧さに合わせ、提案は確認へ回します。
- **読むのではなく、話す。** 書き言葉の定型（「〜において」「〜に際し」「〜につきましては」）は、話し言葉の言い方（「〜で」「〜のときに」「〜は」）に直します。ただし、式辞や公式の挨拶で、改まった言い方が場にふさわしいなら残します。
- **硬さを取ろうとして、雑にしない。** 番組を堅苦しくしまいとして、会話が雑になることもあります（NHK 放送用語委員会 第1297回）。目指すのは、くだけた文ではなく、話して自然な文です。

## 7. 場面ごとの加減

| 場面 | 加減 |
|---|---|
| 挨拶、司会、研修の冒頭 | 呼びかけと定型の挨拶は残す。本題は言い切ってから例を挙げる。締めの挨拶は前の文と同じ段落にまとめてよい |
| スピーチ（結婚式、式典） | 書き手の声と思い出の語り口を残す。文語調の名文に直さない。長い連体修飾をほどき、聞き手が場面を一つずつ思い浮かべられるようにする |
| ナレーション | 映像や音と一緒に聞かれる。一文を短めにし、主語と述語を近づける |
| 館内アナウンス、電話の案内 | 聞き返せない場面。一度に伝えることを絞り、いちばん大事なこと（何をしてほしいか、どこへ行けばよいか）を先に言う。時刻、場所、番号は一字も変えず、はっきり聞こえる形にする。原文が要点を繰り返していれば残す |
| ニュース、報告 | 結論を先に言い、詳しいことを続ける。数字は聞いて分かる形にする |

---

## 8. この種類で気をつける「守ること」

読み上げ向けに言い換えるときこそ、`SKILL.md` の「守ること」を崩しやすくなります。

- **つなぐ言葉で、関係を足さない。** 二つの文をつなぐときに「ので」「ため」「が」を使うと、原文にない因果や逆接を足すことになります。原文が並べているだけなら、「〜し、」「〜て、」「〜ており、」のように、関係を足さない形でつなぎます。因果を足したほうが自然に聞こえるときは、確認へ回します。
  - 例：「動画は〇〇分ほどです。『…』という視点で視聴してください」は、長さを伝えただけで文が終わり、依頼から切り離されて聞こえます。「〇〇分ほどですので、」とつなぐと、長さが理由のように聞こえます。関係を足さずにつなぐなら、「〇〇分ほどの動画を、『…』という視点で視聴してください」のように、前の文の中身を後ろの文に組み込みます。「動画は〇〇分ほどで、」とつなぐこともできます。
- **事実を足さない。** 「報告」の宛先のように原文にない情報は、補いたくなっても補いません。確認へ回します。
- **言い換えで中身を変えない。** 「安全管理措置」のような法令の用語や、正式な名称、日時、場所、番号は、言いやすさのために変えません。

## 9. 出力の形

出力の基本は `SKILL.md` のとおりです。読み上げ原稿では、次の点を加えます。

- **冒頭の一行**で、読み上げ原稿として扱ったことを示す。推定に自信がないときは、「目で読む文書でしたらお知らせください」と添える。
- **校正後の本文に、声にならない記号を残さない。** 伏せ字だけは残し、確認へ回す。
- **読みの注記**：読み間違えやすい語、同じ音の語、読み方が二とおりある数字は、「主な修正」の表か「確認してほしい点」に、読みを示す（例：市立（いちりつ））。本文にはルビや括弧を入れない。
- **区切りの記号（／や改行）は加えない。** 段落は、話の区切りに合わせて整える。
